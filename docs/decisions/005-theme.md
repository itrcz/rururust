# 005. Тема: цвета и размеры встроенных виджетов

**Решение.** `Theme` (`src/theme.rs`) — обычная структура с публичными полями, без ключей и
макросов: `color: Palette` (bg/surface/raised/popover, text/text_muted, border/divider,
accent/on_accent, fill/fill_strong, hover/pressed, selection/focus, scrim, link,
danger/success/warning), `space`, `radius: Radii`, `text: TypeScale` из
`TextStyle { size, line_height, weight, tracking }`, `control: Controls` (отступы, радиусы,
высоты, кольцо фокуса, скроллбар, тултип), `shadow: Shadows` (control/lift/popover/tip/bar),
`motion: Motion` (пружины и задержка тултипа), стекло таб-бара и пикера, а также
`menu: Option<MenuStyle>` и `slider: Option<SliderStyle>` — `None` выводит их из палитры
(`MenuStyle::from(&theme)`), так правка палитры доходит до меню и слайдера.
`Theme::dark()` (по умолчанию), `Theme::light()`, `.accent(c)` (вместе с выделением, фокусом и
тумблером).

**Доставка.** `Ui` держит `Rc<Look>` — тему и выведенные из неё стили, собранные один раз при
смене темы. Задать: `App::theme(t)` / `ui.set_theme(t)`; от состояния — `theme_with(|s| …)`
(вычисляется перед кадром, при равенстве ничего не меняется); за системой — `App::theme_auto(light, dark)`
(winit `ThemeChanged`). View-функция видит `env.theme`.

- Конструкторы больше не зашивают цвета: `button`, `text_field`, `picker`, `tab_bar` помечают
  узел ролью (`Style::role`), `text()` — ролью текста. Сразу после `view()` (и для каждой строки
  ленивого `list`) один проход `theme::apply` дописывает то, что модификаторы не задали.
  Явный модификатор всегда побеждает: у `Option`-полей это `Some`, у отступов и радиуса — биты
  `Style::set` (по сторонам, поэтому `.padding_h()` на кнопке оставляет вертикальный отступ темы).
- Виджеты без узловых стилей (тумблер, слайдер, меню, скроллбар, оверлеи, кольцо фокуса,
  каретка, выделение, выпадающий список пикера) читают тему в `layout`/`Painter` (`Lx::look`,
  `Painter::look`). Дерево после прохода конкретное — layout остаётся однопроходным.
- Тултип из `.tooltip(label)` хранится текстом и строится с темой в том же проходе.
- Фон окна: `ui.background: Option<Color>`, `None` = `theme.color.bg`. Цвет текста по умолчанию —
  `theme.color.text` (раньше выводился из яркости фона).

**Совместимость.** `Theme::dark()` = прежние значения (системные цвета iOS, метрики «под палец»:
тело 17, кнопка 20×13 r14, поле r12, тумблер 51×31), поэтому без `.theme()` кадры showcase и
`menus` совпадают попиксельно. Компактные метрики macOS (13 pt, контролы 22–28) не стали
умолчанием: фреймворк один для телефона и десктопа, а GromAgent задаёт свои мерки сам. Сдвиги
по мелочи: фон меню по умолчанию `#2A2A2C` → `popover #2C2C2E`, тень ручки слайдера = тень
тумблера, тень списка пикера = тень таб-бара.

**Не делаем.** Каскад темы на поддерево (одна тема на окно; поддереву — модификаторы), строковые
токены, наследование стилей через контекст в layout, анимацию смены темы.
