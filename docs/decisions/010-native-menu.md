# Нативная строка меню macOS

Приложение передаёт `App::native_menu` декларативное описание меню и обработчик
числовых команд. AppKit владеет строкой меню и стандартными оконными действиями.
Редактирование и shortcuts поступают в Ui активного окна через очередь событий;
обработчик Objective-C не заимствует Runner во время вложенного цикла AppKit.
Описание сравнивается после событий, позволяя обновлять язык и доступность без polling.
На других платформах API сохраняется, системное меню пока не создаётся.

Проверено: `cargo test --offline` (24 unit, 186 interaction, 7 doctests), сборка
web/dist, открытие showcase в Chromium и WebKit (canvas есть, ошибок страницы нет,
снимки просмотрены). Web-сборщик сохраняет прежнее предупреждение wasm-bindgen
о `strip` и секции `target_features`. Нативные AppKit-меню требуют отдельной живой
проверки в приложении-потребителе; headless-снимок canvas их не показывает.
