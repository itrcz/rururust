# Индикатор в конце потока текста

`View::text_cursor` помечает последний текстовый узел составного view (порядок дерева,
включая body Markdown-кода, независимо от sticky paint order). Невидимый `Span::space`
резервирует ширину только в конце строки и участвует в переносе; при копировании слот
исключается. Painter берёт позицию слота из shaping, поэтому маркер следует за последней
строкой rich text и code. Большой ожидающий квадрат периодически переворачивается вокруг
вертикальной оси; в паузе используется wake deadline, кадры запрашиваются только во время
видимого движения. Снятие модификатора удаляет и маркер, и его анимацию.
