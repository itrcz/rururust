# 012. Нативная диктовка macOS

`VoiceSession` доступен под feature `app`; ядро без GPU и web не подключают Apple frameworks.
Другие платформы возвращают явную ошибку доступности. SDK содержит AVAudioEngine и
SFSpeechRecognizer; проверены Apple headers и objc2-speech 0.2.2. Выбрана небольшая
Objective-C ARC прослойка без новых Rust-зависимостей: это упрощает время жизни tap/blocks
и владение объектами на разных потоках. `build.rs` компилирует её только для macOS + app;
во время работы приложения Swift, компилятор и внешние CLI не нужны.

Исключение для FFI остаётся внутри дерева `macos`: Rust unsafe расположен в
`src/macos/voice.rs`, ARC — в `src/macos/voice.m`. Обработчик принадлежит нативной сессии,
освобождается ровно один раз из dealloc; ожидающие разрешения удерживают отменённый объект,
но после отмены не включают микрофон. Rust handle не Send/Sync и вызывается только с UI-потока.
Audio tap удерживает собственный неизменяемый request, отмена отмечается атомарно; callbacks
передаются в приложение через Link. Они не меняют UI непосредственно.

Разрешения запрашиваются исключительно из `start` после пользовательского клика. `finish`
останавливает AVAudioEngine, удаляет tap и завершает вход Speech, затем выдаёт текст или ошибку.
Отмена и Drop выключают запись и отбрасывают результат. Завершение ограничено таймером 15 с;
он не рисует кадров. Уровень RMS берётся из микрофона не чаще 20 Гц. Аудиофайлы не создаются.
Если язык поддерживает on-device recognition, запрос требует его; иначе Apple Speech может
обрабатывать звук на своём сервере. Это указано в системном описании разрешения.

Приложение обязано включать NSMicrophoneUsageDescription и NSSpeechRecognitionUsageDescription
в Info.plist, в том числе в __TEXT,__info_plist для cargo run. Предварительная проверка
возвращает ошибку до запроса разрешения, если ключей нет. Автоматические тесты не открывают
микрофон: проверяют передачу/владение событиями и отклонение запуска с рабочего потока.
Первое разрешение, реальные уровни, диктовку и смену аудиоустройства проверяют вручную.
