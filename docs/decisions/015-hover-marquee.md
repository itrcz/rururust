# 015 — Однократное раскрытие длинной строки при наведении

Для узких списков добавляем `text(...).hover_marquee(speed, trailing_inset, fade_width)` и `.hover_scope()` на строку списка. Без наведения текст занимает всю доступную ширину и жёстко обрезается по краю. При наведении ширина маски уменьшается на место наложенных действий, текст один раз плавно прокручивается до конца и останавливается. Если текст помещается, анимация не запускается; уход мыши сразу возвращает начало.

Layout один раз шейпит полную строку и сохраняет её естественную ширину. Paint меняет только позицию текста и clip/fade. Состояние движения живёт в Ui по стабильному id и очищается, когда узел пропадает. В конце движения нет ни redraw, ни таймера. Hover scope связывает текст и расположенные поверх него кнопки без состояния в приложении и без перехвата их кликов. Шейдер и формат draw-команд остаются прежними.
