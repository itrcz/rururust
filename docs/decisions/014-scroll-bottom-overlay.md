# Измеряемый нижний слой scroll

`Scroll.bottom_overlay(view)` размещает плавающий нижний слой поверх прокручиваемого содержимого. Layout измеряет слой один раз до содержимого, затем добавляет его фактическую высоту к диапазону прокрутки и нижнему отступу scrollbar. Содержимое может проходить под прозрачным слоем, но в конечной позиции остаётся над ним.

Второго layout и обратной связи через состояние нет. Основное содержимое сохраняет child index 0, слой — index 1. Тема, selection traversal и paint используют тот же порядок дерева. Внешние padding/insets складываются с измеренной высотой; layout не оценивает символы или высоту строк прикладным кодом.
