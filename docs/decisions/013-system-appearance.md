# 013. Системная и выбранная тема

`Ui.system_dark` хранит последнее значение платформы; `Env.system_dark` передаёт его view.
`theme_with_system(|state, system_dark| Theme)` позволяет приложению хранить выбор
System/Light/Dark. Значение ОС не затирается выбранной темой, поэтому возврат в System
сразу использует последнюю системную настройку. Старый `theme_with` сохраняет API.
Провайдер вызывается после inbox/timers, до построения дерева, без дополнительного кадра.

Runner получает начальную тему из `Window::theme()` и обновляет её по `ThemeChanged`.
Winit на web уже слушает prefers-color-scheme; опрос и самостоятельные таймеры не нужны.
На macOS NSVisualEffectView получает resolved `Theme.dark` после построения текущего кадра.
Самому NSWindow appearance не назначается: по исходникам winit 0.30 явное appearance окна
отключает события смены системной темы, что ломало бы последующий выбор System.
Кастомный titlebar приложения окрашивается семантической палитрой вместе с остальным view.

Framework не инвертирует draw commands, изображения, SVG и содержимое файлов. Приложение
выбирает явные светлые/тёмные цвета. Headless-тесты задают system_dark напрямую, не изменяя
настройки компьютера, и проверяют override, возврат в System и отсутствие idle-перерисовок.
