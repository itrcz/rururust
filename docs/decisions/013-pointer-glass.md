# Подсветка с притяжением к указателю

Для области приёма файлов используем существующее стекло: необязательный модификатор
`glass_attraction(strength, frost)` смещает выборку подложки к указателю визуально и
усиливает размытие рядом с ним. Границы области остаются неподвижными. Layout и hit testing
не деформируются. Значения эффекта задаёт продукт, механизм — ruru.

`fade(shown)` использует механизм reveal с плавной пружиной темы, но только opacity,
без масштабирования. Скрытый слой по-прежнему не принимает ввод.

Во время внешнего file drag macOS может не присылать CursorMoved. Runner считывает
положение указателя относительно content view только пока активен file hover;
после drop/cancel дополнительное обновление прекращается.
