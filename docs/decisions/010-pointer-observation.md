# Наблюдение за курсором без захвата ввода

`View::track_pointer` явно включает наблюдение за мышью в окне для видимого узла.
Обработчик получает локальные координаты, в том числе за пределами узла, и `None` при
выходе из окна. Наблюдение не создаёт hit-target и не меняет обработку кликов/drag.
Скрытые и отсечённые узлы не регистрируются; без наблюдателей обычное движение не
требует кадра. Это позволяет небольшим интерактивным иллюстрациям следить за курсором
без постоянно работающего цикла отрисовки и без платформенных зависимостей ядра.

Короткие анимации могут планировать конечную цепочку `after`. Таймер, созданный другим
таймером, учитывается в `wake_in` того же кадра; после последнего callback UI засыпает.
