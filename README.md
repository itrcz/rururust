# ruru

Маленький и быстрый UI-фреймворк на Rust с настоящим стеклом (преломление, матирование,
слипающиеся панели). Один код — нативно (macOS / Windows / Linux / iOS / Android) и в браузере
на `<canvas>`.

```rust
use ruru::prelude::*;

struct Counter { n: i32 }

fn view(s: &Counter) -> View<Counter> {
    vstack((
        text(s.n.to_string()).font_size(64.0).weight(Weight::Bold),
        button("Add one", |s: &mut Counter| s.n += 1),
    ))
    .spacing(16.0)
    .padding(24.0)
    .glass()
    .radius(28.0)
}

fn main() {
    App::new(Counter { n: 0 }, view).run();
}
```

## Запуск

```sh
cargo run --release --example showcase                       # окно (меняй размер: телефон → планшет → десктоп)
cargo run --release --example showcase -- --screenshot a.png # рендер в PNG без окна
cargo run --release --example menus                          # меню, поповеры, тултипы, контекстное меню, шорткаты
./web/build.sh && python3 -m http.server -d web 8080          # браузер: http://localhost:8080
./web/build.sh menus                                          # другой пример в браузере: http://localhost:8080/?ex=menus
cargo test
```

Нужен Rust (https://rustup.rs). Для браузера дополнительно:

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.130 --locked   # версия как в Cargo.lock
```

Страницу надо открывать через http-сервер, а не как файл.

| Раскладка | `vstack` `hstack` `zstack` `spacer` `rect`, `.padding()` `.padding_h()` / `.padding_v()` (складываются; у всех узлов отступ внутри — и у тумблера, слайдера, меню, таб-бара, картинки) `.size()` `.fill_width()` `.place()` |

| Углы | `.radius(r)` — круговая дуга, как в macOS; `.smooth()` — непрерывные углы-сквирклы, как в iOS (у стекла всегда) |
| Анимация размера | `.animate()` — новый размер узла доезжает пружиной, содержимое режется краем, а не сжимается: `sidebar.width(if open { 280.0 } else { 0.0 }).animate()`. | Markdown | `markdown(src)` / `markdown_with(src, images)`; `markdown_styled(src, &MarkdownStyle { size: 14.0, line_height: 1.625, strong: Weight::Semibold, code_background: Some(c), ..MarkdownStyle::from(&*env.theme) })` — кегль, межстрочный, отступ между блоками, цвет и иконки ссылок (`link_icons`: по префиксу URL), заголовки, inline-код, `code_block`, `table` (`TableStyle`: кегль, поля ячеек, линии между строками, вес шапки, `columns` — доли ширины), `quote`; `Default` = вид `markdown()` в тёмной теме; таблицы — колонками |
| Появление текста | `.text_reveal(0.22)` на тексте или Markdown — новые графемы плавно проявляются из размытия, уже написанное остаётся чётким. Только отрисовка: размеры, переносы и выделение не меняются. Применять к живому ответу; после завершения убрать модификатор. |
| Картинки и иконки | `image(&Image)`, `icon(&Image)` — глиф, красится цветом текста; `Image::decode` (PNG/JPEG), `Image::from_svg` |

Модель: состояние `S` → `view(&S)` → дерево → layout → draw list → GPU. Обработчики — замыкания
`Fn(&mut S)`. Кадр рисуется только по событию, по таймеру или пока идёт анимация.

Фоновая работа: обновления состояния приходят из другого потока через `Link` и применяются в начале
следующего кадра. Пока `Task` жив, работа идёт; сбросил его (`s.reply = None`) — отменилась.

```rust
s.reply = Some(spawn(|link: Link<App>| async move {
    for word in answer.split_inclusive(' ') {
        if link.cancelled() { return; }
        sleep(0.03).await;
        link.send(move |s| s.text.push_str(word));
    }
}));
```

Кто встраивает `Ui` без `app`, сам вызывает `set_waker` (на UI-потоке, чтобы `send` будил цикл), а на wasm
ещё и `set_spawner`.

## Тема

Цвета и размеры встроенных виджетов — в одной структуре `Theme` с публичными полями
(`src/theme.rs`): `color` (bg, surface, raised, popover, text, text_muted, border, divider, accent,
on_accent, fill, fill_strong, hover, pressed, selection, focus, scrim, link, danger, success, warning),
`text` (large_title, title, headline, body, subhead, footnote, caption, caption2 — `TextStyle { size,
line_height, weight, tracking }`), `control` (отступы, радиусы, высоты, кольцо фокуса, скроллбар, тултип, ширина затухания `fade_width`, радиус выделения текста),
`shadow`, `motion` (пружины, затухание слоёв, задержка тултипа, нажатие, масштаб появления `reveal` и поповеров, возврат marquee), `space`, `radius`, стекло таб-бара и пикера, `menu` /
`slider` (`None` — выводятся из палитры), `font` / `mono` — шрифт текста и кода.

Шрифт: `Theme::dark().font(Font::System)` — `Font::Bundled` (Inter + JetBrains Mono, по умолчанию,
одинаково везде), `Font::System` (macOS — San Francisco и SF Mono, Windows — Segoe UI Variable / Segoe UI и
Cascadia Mono / Consolas, Linux — Cantarell / Ubuntu / Noto Sans / DejaVu Sans), `Font::Named("…".into())`.
Не найденный шрифт (на web — любой системный) тихо заменяется встроенным. У системного SF на macOS
шейпер не двигает ось оптического размера: рисуется дизайн 28 pt, а разрядка до ширины AppKit
добирается таблицей (ширина строки ±0.5 %); x-height всё равно ниже на ~3.5 % (0.508 em против 0.526), штрих светлее.
Заголовки темы (`large_title`, `title`) сжаты по таблице Inter (`inter_tracking(size)`: −1.8 % при 22,
−2.2 % при 34); с другим шрифтом `.font()` возвращает им 0.

```rust
App::new(state, view).theme(Theme::light().accent(Color::hex(0x4D81EF)));      // одна тема
App::new(state, view).theme_with(|s: &State| if s.dark { Theme::dark() } else { Theme::light() }); // от состояния
App::new(state, view).theme_auto(Theme::light(), Theme::dark());               // за системой
ui.set_theme(Theme::light());                                                  // без окна

fn view(s: &State, env: &Env) -> View<State> {
    let t = &env.theme;
    vstack((
        text("Settings").style(t.text.title),                      // кегль, межстрочный, вес, разрядка разом
        text("Synced").style(t.text.footnote).color(t.color.text_muted),
        button("Save", save),                                       // accent, on_accent, отступы и радиус — из темы
        button("Delete", del).background(t.color.danger),           // модификатор на узле всегда побеждает тему
    ))
}
```

`Theme::dark()` — тема по умолчанию, совпадает с прежним видом (системные цвета iOS, контролы «под
палец»). `.accent(c)` красит кнопки, слайдеры, тумблеры, кольцо фокуса, каретку и выделение. Фон окна —
`theme.color.bg`, если не задан `App::background`. Свой стиль меню или слайдера от темы:
`MenuStyle { row_height: 24.0, ..MenuStyle::from(&*env.theme) }`, так же `SliderStyle::from`,
`MarkdownStyle::from`. Одна тема на окно: поддерево перекрашивают модификаторы. Решение —
`docs/decisions/005-theme.md`.

## Брать только часть

```toml
ruru = { version = "0.1", default-features = false }                            # дерево, layout, ввод, анимации, текст → DrawList
ruru = { version = "0.1", default-features = false, features = ["renderer"] }   # + wgpu-рендерер: встроить в свой движок
ruru = { version = "0.1", default-features = false, features = ["app"] }        # + окно и цикл событий
```

Дополнительно: `decode` (PNG/JPEG), `svg`, `markdown` (+ моноширинный шрифт), `headless`, `webgl`
(запасной путь для браузеров без WebGPU, ~1 МБ wasm). `Ui` не знает про окно: ему передают
размер и события (`frame`, `pointer_down/move/up`, `wheel`, `key`, `text_input`, `set_modifiers`, `paste`,
`ime_preedit`), он отдаёт `DrawList` и просьбы к окну в `ui.requests` (`DragWindow`, `Zoom`,
`SetClipboard(текст)`, `OpenUrl(url)`); `ime_area()` — где показать окно IME. Фича `clipboard` (по умолчанию) —
системный буфер на десктопе через `arboard` (+18 КБ к бинарнику); без неё буфер внутренний.

Размер. wgpu подключён без своих фич по умолчанию: только фронтенд WGSL и бэкенды платформы — Metal на
macOS/iOS, DX12 + Vulkan на Windows, Vulkan + GLES на Linux/Android, WebGPU (+ WebGL2 с фичей `webgl`)
в браузере. Обычный `--release` собирается быстро; компактный профиль `--profile dist` (его же использует
`web/build.sh`) — `lto = "fat"`, `codegen-units = 1`, `strip = true`: showcase ≈ 7,4 МБ
нативно, wasm ≈ 7,9 МБ (≈ 2,9 МБ gzip). Делайте так же в своём приложении — fat LTO против thin
даёт −23%, `opt-level = "s"` ещё −16% ценой скорости. Минимальная сборка — `default-features = false`
и только нужное из `app`/`renderer`, `decode`, `svg` (≈ 0,4 МБ: usvg + tiny-skia), `markdown`
(≈ 0,1 МБ кода + моноширинный шрифт), `headless`, `webgl` (≈ 1 МБ wasm), `clipboard`.

## Как устроено

| Файл | Что делает |
| --- | --- |
| `src/view.rs` | Декларативное дерево `View<S>`, конструкторы и модификаторы |
| `src/layout.rs` | Однопроходный layout в духе SwiftUI; id узлов для состояния между кадрами |
| `src/ui.rs` | Ядро без привязки к платформе: покраска в `DrawList`, пружины, физика скролла, ввод, таймеры |
| `src/render.rs` | wgpu: один инстансный пайплайн на все фигуры, снимок сцены + пирамида размытия для стекла |
| `src/shaders/` | SDF-сквирклы, градиенты, тени, стекло (преломление по Снеллу, дисперсия, слияние панелей) |
| `src/text.rs` | Шейпинг и кэш текста (cosmic-text), встроенные шрифты Inter и JetBrains Mono; геометрия текста: точка ↔ байт, каретка, прямоугольники выделения, слово / абзац |
| `src/edit.rs` | Редактор `text_field`: каретка, выделение, undo, буфер обмена, IME, многострочность (подмодуль `ui`) |
| `src/select.rs` | Выделение и копирование read-only текста (`.selectable()`), ссылки (подмодуль `ui`) |
| `src/popup.rs` | Слои над деревом: поповеры, меню с подменю и клавиатурой, контекстные меню, тултипы; шорткаты (подмодуль `ui`) |
| `src/task.rs` | Канал «фон → состояние»: `Link`, `Task`, `spawn`, `sleep`, `Ui::pump` |
| `src/markdown.rs` | Markdown → обычные view |
| `src/app.rs` | Окно и события (winit), один путь для native и web |

Приёмы стекла взяты из [liquid-rust](https://github.com/al1h3n/liquid-rust) (MIT/Apache-2.0).

## Известные проблемы и чего пока нет

- WebKit под WebGPU иногда теряет `queue.writeTexture` (пропадали буквы). В `app.rs` стоит обход:
  в WebKit загрузки текстур идут через `copyBufferToTexture`. Кто встраивает только `renderer`
  в свою web-страницу, обход не получает. В настоящем Safari не проверено.
- Поля ввода: в браузере нет IME и экранной клавиатуры (нет скрытого DOM-поля; символы, которые браузер
  вставляет не через `keydown`, — IME, эмодзи-панель, диктовка — теряются); буфер обмена в вебе работает
  через события `copy`/`cut`/`paste` (Chromium; Safari может их не присылать без DOM-выделения).
  На Linux системный буфер — только X11 (под Wayland через XWayland). Нет тач-выделения (ручек),
  контекстного меню, двунаправленного текста сверх того, что даёт cosmic-text.
- Выделение текста в ленте (v1): только мышь — нет тач-выделения (long-press, ручки), протяжки по
  словам после двойного клика, Shift+стрелок; копируется только plain text (без rich/HTML); область —
  один `list` либо поддерево без списка (вложенные списки в одной области не поддержаны); картинки
  при выделении не подсвечиваются (но копируются через `.copy_as`); вставка строк в начало ленты
  сдвигает выделение (при уменьшении числа строк оно сбрасывается), стриминг текста под выделением
  может сдвинуть его край. В вебе текст для `copy` пересобирается только при смене выделения: если
  текст под неизменным выделением дописался, копируется прежний. `OpenUrl` на iOS/Android пока
  ничего не делает.
- У таблиц нет выравнивания колонок (`:---:`) и ширины по содержимому — только доли.
- Резинка и pull-to-refresh от трекпада работают только на macOS (нужны фазы жеста); в браузере и
  с мышью скролл останавливается на краях. Тач-перетаскивание работает везде.
- Нет accessibility, тем, горизонтального скролла, диффинга дерева.
- Сборки под iOS/Android/Windows/Linux не проверялись.

Модальные окна (`modal`) появляются через прозрачность без масштабирования текста;
подложка блокирует клики, наведение, смену курсора и подсказки элементов под ней.
`.modal_style(ModalStyle { rise: 18.0, backdrop: Some(glass) })` добавляет короткий подъём
снизу и размытие фона под подложкой. Сам диалог рисуется после размытия и остаётся резким.
По умолчанию подъём и стекло выключены; оттенок затемнения берётся из темы.

`text("Thinking…").text_shimmer(1.8, Color::WHITE)` — мягкий блик по тексту без изменения раскладки; удаление модификатора прекращает перерисовки.

### Дополнительное окно на desktop

`App::companion(other_app, is_visible, close)` добавляет независимое нативное окно на общий
цикл событий. `is_visible` возвращает `None` для скрытого окна и `Some(activation)` для
видимого; увеличение `activation` снова поднимает его на передний план. У окна собственные
размеры, тема, фокус и состояние отдельного типа. Обновления
передаются через `Link<T>`. Первое открытие создаёт окно рядом с главным; закрытие вызывает
`close`, скрытие прекращает отрисовку. Главное окно продолжает работать и завершает приложение
при собственном закрытии. Окна-компаньоны прикрепляются только к главному `App`.


`View::glass_fade(height)` плавно сводит стеклянный материал к исходному фону на нижних `height`
точках, сохраняя непрозрачность содержимого. Это один стеклянный слой с одним снимком фона;
подходит для sticky-шапок. `CodeHeaderStyle::fade` использует его для шапок блоков кода.


`ruru::pick_folder()` открывает нативный выбор директории из обработчика UI. На macOS это
NSOpenPanel, возврат — `Option<PathBuf>`; отмена даёт `None`. На других платформах диалог пока
не реализован и возвращается `None`.

Выбор углов: `.radius(16.0).round_corners([true, false, false, false])` оставляет скруглённым только верхний левый угол (порядок — по часовой стрелке). Фон, обводка, тени и `.clip()` используют одну форму.

`.mask_corners(color, [false, false, true, true])` закрывает цветом внешнюю область нижних скруглений, сохраняя содержимое и просвечивание внутри стекла. Маска точно следует измеренному размеру виджета и не влияет на раскладку. Вариант `.mask_corners(...).mask_under()` закрывает только фон до рисования поверхности и её теней: мягкая тень не обрезается в углах.

`Glass { horizontal_light: true, ..Glass::regular() }` ограничивает блики верхним и нижним краем. Боковые грани остаются без светлой подсветки, преломление работает по всему контуру.

У `split(...).highlight_main_border()` подсветка наведения и перетаскивания следует всей обводке основной панели, включая её скруглённые углы. Отдельная прямая линия-разделитель не рисуется; область захвата и жесты сохраняются.

`.border_edges([true, false, false, true])` оставляет верхнюю и левую грани обводки. Соседние видимые грани соединяются скруглением; скрытые грани не сужают область отсечения содержимого. Работает и с подсветкой рамки у `split`.

`split(...).highlight_main_border_fade(0.2).resize_grip()` плавно возвращает подсветку к обычному цвету на первых 20% ширины и показывает ручку захвата посередине разделителя. Ручка растягивается при наведении и перетаскивании, затем возвращается без постоянной перерисовки; размеры задаёт `theme.control.split_grip`.

`.animate_radius()` плавно меняет `.radius()` при изменении состояния; фон, обводка и clip используют один радиус, после завершения перерисовки прекращаются.
`split(...).resize_grip_at_bottom(22.0)` выравнивает центр ручки по заданному отступу от нижнего края (например, напротив профиля). Ручка ограничена высотой разделителя при растяжении.

Для inline-редактирования: `.on_double_tap(...)` открывает поле; `text_field(...).autofocus().select_on_focus().on_blur(...).on_cancel(...)` поддерживает выделение имени, сохранение при потере фокуса и отмену Escape. Автофокус срабатывает один раз при появлении поля.

`text_field(...).fit_content()` задаёт ширину по шейпингу текста и растёт до доступной ширины родителя; `.weight(...)` и `.style(...)` сохраняют метрики при переключении текстовой подписи в редактор.

`view.track_pointer(|state, position| ...)` наблюдает мышь во всём окне, пока view
виден: локальные координаты могут выходить за bounds, `None` означает выход из окна.
Клики и drag не захватываются; обычные views без подписки не перерисовываются от движения.

`split(...).hide_collapsed_divider()` скрывает разделитель, подсветку и resize-зону свёрнутой панели. Уже начатый drag можно развернуть до отпускания; новый drag от края не раскрывает панель. По умолчанию сохраняется прежнее раскрытие от края.

`text(...).text_reveal_center(seconds, stagger)` проявляет неподвижные Unicode-графемы из блюра от центра к краям, с задержкой между наружными парами. Эффект использует тот же рендер, что `text_reveal`; стабильный `.key()` сохраняет прогресс при перестроении, после окончания кадров и таймеров нет.

`view.text_cursor(TextCursor { size, reserve, gap, radius, color, cycle_period, transition_duration })`
добавляет маркер к последнему логическому текстовому узлу, в том числе телу кода под липкой
шапкой. `reserve` — максимальный размер маркера для устойчивых переносов; невидимый
`Span::space(points)` занимает место и исключается из копирования. Нулевой `cycle_period`
даёт статичный курсор без кадров; вне видимой области таймер перехода не запускается.

`App::on_file_drop(|state, path| ...)` получает каждый файл из нативного drag-and-drop,
а `.on_file_hover(|state, over| ...)` включает и сбрасывает подсветку при наведении,
отмене и отпускании. Обработчики относятся только к своему окну; framework не читает файлы.
`ruru::pick_files()` открывает на UI-потоке macOS нативный диалог с множественным выбором:
`Ok(Vec::new())` означает отмену, другие платформы возвращают понятную ошибку.

`VoiceSession::start("ru-RU", callback)` включает нативную диктовку macOS после явного
пользовательского действия. `VoiceEvent` сообщает Ready, Level(0..1), Transcribing и Text/Error;
callback может приходить с другого потока, поэтому используйте `Link`. `finish()` выключает
микрофон и завершает распознавание, `cancel()` и Drop отбрасывают результат. Handle принадлежит
UI-потоку. Нужны ключи разрешений микрофона и Speech в Info.plist; другие платформы возвращают
ошибку доступности. Подробнее: [решение 012](docs/decisions/012-native-voice.md).

`App::theme_with_system(|state, system_dark| Theme)` (и одноимённый метод `Ui`) поддерживает
настройку System/Light/Dark приложения. `Env.system_dark` всегда отражает последнее событие ОС,
а `Env.theme.dark` — выбранную тему. Смена происходит сразу, без опроса и перекрашивания
изображений; для headless можно явно задать `ui.system_dark`.

`activity_indicator(size, stroke, period)` — плавное кольцо активности с цветом из `.color()`. Период задаётся в секундах; анимация не запрашивает кадры вне видимой области.

Индикатор `TextCursor` с положительным `cycle_period` плавно меняет квадрат на треугольник и круг, слегка поворачиваясь во время перехода. Фигуры рисуются одним SDF-квадом, без SVG-растеризации; между переходами работает таймер, вне clip пробуждений нет.

Ленивый список внутри `stick_to_bottom()` измеряет последние строки в пределах высоты
viewport до выбора scroll offset. Поэтому первый кадр нового чата сразу показывает
реальный конец длинного ответа, без промежуточного прыжка по оценочным высотам;
остальные строки остаются ленивыми. Для переключаемых лент используйте стабильный `.key(id)`.

`.hover_offset(x, y)` плавно сдвигает дочерний вид внутри `.hover_scope()` без изменения раскладки. Область клика следует за видимой позицией.

Picker применяет `.font_size()`, `.style()`, `.weight()`, `.line_height()` и `.letter_spacing()` и к выбранной подписи, и к раскрытому списку. Заданная высота контрола центрирует подпись, не увеличивая шрифт; метрики строк списка берутся из `Theme.control.picker_row`.

`scroll(content).bottom_overlay(composer)` измеряет плавающий нижний слой и резервирует его фактическую высоту в конце содержимого и у scrollbar. Текст продолжает проходить под прозрачным слоем; ручной расчёт высоты многострочного input не нужен.
